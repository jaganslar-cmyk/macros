# Macros

Personal macro tracker PWA (calories, protein, carbs, fat, fibre) with full history and day/week/month trends. Data is stored on-device (localStorage). Optional auto-sync (Settings → Sync) pushes `data.json` to a private GitHub repo using a fine-grained token; JSON/CSV export still available.

Install: open https://jaganslar-cmyk.github.io/macros/ in Safari → Share → Add to Home Screen.
